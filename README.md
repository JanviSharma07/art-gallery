# 🎨 Atelier — Art Gallery Frontend

A modern and responsive React frontend for the **Atelier Art Gallery** web application. The frontend provides an elegant digital gallery experience for discovering artworks, viewing artwork details, acquiring available artworks, tracking orders, and accessing the administrative dashboard.

---

## ✨ Features

- Modern contemporary art gallery interface
- Responsive design for desktop, tablet, and mobile
- Featured artwork section
- Dynamic artwork collection
- Search artworks by title or artist
- Filter artworks by artist
- Artwork availability status
- Artwork details modal
- Artwork acquisition flow
- Customer registration
- Order creation
- Order tracking
- Admin authentication
- Admin statistics dashboard
- Customer and order activity table
- REST API integration with the backend
- Loading and error states
- Responsive navigation and UI components
